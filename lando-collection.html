BASE & PARALLELS

普卡和棋盘格折，差在哪？

BASE

Base 普卡

这一卡面的基础版本。卡图本身的几何背景不等于黑白激光折，判断应结合版本资料，而不是只看灰黑配色。

CHECKER FLAG

黑白棋盘折

本次购入描述使用的名称。对应 Checker Flag 棋盘方格折射纹理，与同卡面 Base 相比，多了格状闪面。

B&W STYLES

名称要区分

黑白激光折 B&W Lazer、黑白波纹折 B&W RayWave 是另两类纹理，不应和这张 Base 或棋盘格折混为一谈。
